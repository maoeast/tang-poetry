《唐诗画境》- 诗歌分类页“新中式古风”进阶设计指南
一、 分类标题（Section Titles）的古风重构系统
针对五绝、七绝、律诗、乐府等所有大分类，我们需要摒弃现代化的“加粗大字+圆角数字标签”模式，建立一套富有层次的“标题组合 (Title Group)”。

1. 方案 A：引首章与金石篆刻（强烈推荐，最具文化感）
在中国传统书画中，起首处常有“引首章”。我们可以把这种形式引入网页。

视觉结构： [红色小方印] + [大字衬线体分类名] + [古典计数]

具体实现：

印章元素： 在“五言绝句”四个大字左侧，放置一个极小、正方形的朱砂红印章（可以是纯 CSS 写的带边框方块，里面用繁体写“五绝”、“七律”、“乐府”的缩写，如 bg-transparent border border-accent text-accent）。

主标题： 使用最大的衬线体（text-3xl font-serif text-ink-900），字间距拉大（tracking-widest）。

古风计数： 把现代的“33 首”灰色胶囊，换成竖排的“共三十三首”或者极简的浅色文字 · 叁拾叁首 ·。

2. 方案 B：传统纹样与线条分割（极简雅致）
如果觉得印章过于显眼，可以使用传统纹样作为标题的修饰。

视觉结构： [传统回纹/水波纹 SVG 图标] + [分类名] + [淡墨分割线]

具体实现：

在标题左侧或正上方，引入一个极简的、低透明度的传统纹样 SVG（如祥云纹、回字纹）。

标题下方拉出一条不贯穿全屏的渐变细线（中间深，两边淡，模拟毛笔笔锋划过的痕迹）。

二、 页面布局的“水墨留白”与呼吸感
从您提供的网页截图来看，目前图片网格非常整齐，但在“画境”的营造上，空间显得略微拥挤。我们需要在布局上做“减法”。

1. 分类之间的“留白 (Whitespace)”
现状： “五言绝句”模块和下方的“七言绝句”模块距离偏近，长列表滚动时容易产生视觉疲劳。

优化建议： 加大不同体裁之间的垂直外边距（Margin）。在 Tailwind 中，将分类区块的底部间距设置得非常夸张（比如 mb-24 或 mb-32），让用户在滑完“五绝”进入“七绝”前，有一个明显的“翻页/喘息”空间。

2. 卡片与网格的物理感知
现状： 截图中的网格有些紧凑，且图片底部的文字部分（诗名+作者）离图片太近，有些局促。

优化建议：

拉开网格间隙： 稍微增大 gap 的值（例如从 gap-4 提升到 gap-6 或 gap-8）。

卡片内留白： 在配图下方和诗名上方，增加更多的 padding-top。

文字对其方式： 考虑将“诗名”与“作者”改为垂直居中对齐（Center-aligned），这在诗词卡片中会比左对齐更具传统的对称美。

三、 现代 Web 技术与古典美学的融合 (SSR 友好)
考虑到应用可能使用了服务器端渲染（SSR）来保证 SEO 和首屏速度，以下细节可以提升质感且不损耗性能：

1. 字体抗锯齿 (Font Smoothing)
对于大号的衬线体标题，一定要在全局或标题上加上 CSS 属性，让文字边缘更锐利，呈现出“印刷古籍”的质感。

Tailwind 类： antialiased 或 subpixel-antialiased。

2. 滚动吸顶的“磨砂玻璃”屏风
当用户向下滚动长列表时，我们可以提供一个横向的快速导航（五绝 | 七绝 | 乐府...）。

设计巧思： 这个吸顶导航不要做成死板的实色，而是使用半透明的宣纸底色加上毛玻璃效果（bg-paper/80 backdrop-blur-md），让背后的诗词卡片在滚动时若隐若现，犹如透过屏风看画。
