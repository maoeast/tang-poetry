**《唐诗画境》- 全局设计规范与重构指南**

## **一、 全局色彩系统 (Color System)**

整体采用“新中式极简”风格，以水墨丹青的低对比度色彩为主，保护视力并提升沉浸感。建议在您的全局 CSS 文件（如 app.css）中使用 Tailwind 4 的 @theme 指令进行注入。

### **1\. 基础色彩定义**

| 颜色角色 | 颜色名 / 色值 | Tailwind 4 Token | 适用场景 |
| :---- | :---- | :---- | :---- |
| **页面底色** | 宣纸白 \#F7F5F0 | bg-paper | 全局 \<body\> 背景色，营造温润质感。 |
| **卡片底色** | 纯净白 \#FFFFFF / \#FCFAF5 | bg-surface | 图片容器、独立面板的背景，配合轻微阴影。 |
| **主品牌色** | 黛蓝 \#354E6B | text-primary / bg-primary | 核心操作（如播放按钮）、当前选中状态、强调文字。 |
| **辅助强调色** | 朱砂红 \#B84B4B | text-accent | 错题高亮、未掌握标记、仿印章 UI。 |

### **2\. 文本墨色层级**

| 文本角色 | 色值 | Tailwind 4 Token | 适用场景 |
| :---- | :---- | :---- | :---- |
| **主文本 (深墨)** | \#2C2C2C | text-ink-900 | 诗词大标题、正文、重要数据。 |
| **次文本 (灰墨)** | \#666666 | text-ink-600 | 译文、作者简介、次要 UI 文本。 |
| **弱文本 (浅灰)** | \#999999 | text-ink-400 | 拼音、次要标签、禁用状态、时间戳。 |

**二、 字体与排版规范 (Typography System)**

在 Next.js 中，建议通过 next/font/google 或本地字体文件引入双字体栈。

### **1\. 字体族 (Font Family)**

* **衬线体 (Serif) \- font-serif：** 用于所有**诗词本体**（标题、正文、作者）。建议使用 Noto Serif SC。  
* **无衬线体 (Sans-serif) \- font-sans：** 用于所有 **UI 控件与数据**（按钮、数据看板、标签）。使用系统默认字体栈即可（PingFang SC 等）。

### **2\. 核心排版层级表**

| 元素级别 | 字体族 | 字号 (Size) | 字重 (Weight) | 行高与间距 (Tailwind Classes) |
| :---- | :---- | :---- | :---- | :---- |
| **页面大标题** | Sans | text-2xl (24px) | font-semibold | leading-snug |
| **诗词标题** | Serif | text-3xl (30px) | font-bold | tracking-wide leading-tight |
| **诗词正文** | Serif | text-lg (18px) | font-normal | leading-loose tracking-widest (关键留白) |
| **数据看板** | Sans | text-3xl (30px) | font-bold | tracking-tight |
| **正文拼音** | Sans | text-xs (12px) | font-normal | text-ink-400 (配合 \<ruby\> 标签) |

**三、 复习页面 (Review Page) 重构方案**

针对您截图中长诗（如《将进酒》）被“过度碎片化”以及布局冗杂的问题，建议按照以下模块自上而下进行重构。

### **1\. 顶部数据看板 (Dashboard) —— “去卡片化”**

**现状：** 4个白色大卡片横排，具有强烈的后台管理系统生硬感。

**调整建议：** 移除白色背景和阴影，让数据直接融入“宣纸”背景，使用雅致的竖线分割。

* **布局逻辑：** 使用 Flexbox，加入垂直分割线。  
* **推荐 Tailwind 结构：**  
  JavaScript  
  \<div className="flex items-center justify-between px-6 py-4 border-b border-ink-200/50 mb-6"\>  
    \<div className\="flex flex-col"\>\<span className\="text-sm text-ink-600"\>批次\</span\>\<span className\="text-xl font-bold text-ink-900 font-sans"\>3 / 3\</span\>\</div\>  
    \<div className\="h-8 w-px bg-ink-200/50"\>\</div\> {/\* 分割线 \*/}  
    \<div className="flex flex-col"\>\<span className\="text-sm text-ink-600"\>今日待复习\</span\>\<span className\="text-xl font-bold text-ink-900 font-sans"\>2\</span\>\</div\>  
    {/\* 依此类推... \*/}  
  \</div\>

### **2\. 诗词元数据与操作区 —— “降噪与分离”**

**现状：** 众多分类标签（黄河、咏物等）与“显示拼音”操作按钮混在一起，缺乏视觉焦点。

**调整建议：**

* **标签弱化：** 将过多标签精简，或统一使用极简的幽灵按钮样式（透明底，极淡边框 border border-ink-200 text-ink-400 text-xs rounded-full px-3 py-1）。  
* **操作分离：** 将“显示拼音”做成一个带有清晰 Toggle UI 的开关，放置在容器右上角，明确其“动作”属性。

### **3\. 长诗正文区 —— “回归文本流与卡拉 OK 高亮”**

**现状：** 《将进酒》被拆分为一个个气泡，破坏了杂言诗的节奏与排版美感。

**调整建议：**

* **绝对移除气泡背景：** 让文字直接呈现在大面积的米色或白色容器中。  
* **实现优雅的朗读跟随 (React 19 最佳实践)：** 不需要将句子切分成卡片。使用 React 的状态来映射当前朗读的句子索引 (currentLineIndex)，通过动态改变 Tailwind 的透明度与字重来实现高级的焦点效果。  
* **实现思路示例：**  
  JavaScript  
  {poemLines.map((line, index) \=\> (  
    \<p  
      key\={index}  
      className\={\`font-serif text-lg tracking-widest leading-loose transition-all duration-300 ease-in-out  
        ${index \=== currentLineIndex ? 'text-ink-900 font-bold scale-105 origin-left' : 'text-ink-400 opacity-70'}  
      \`}  
    \>  
      {line.text}  
    \</p\>  
  ))}

### **4\. 底部播放与自评控制区 —— “沉浸式悬浮栏 (Sticky Footer)”**

**现状：** 播放按钮和自评按钮在页面最底部，长诗需要一直滚动到底才能操作，且 UI 具有断层感。

**调整建议：**

* **全局悬浮：** 将播放控制（暂停、重播）和自评选项（会背了、还不熟）整合到一个底部容器中。  
* **毛玻璃效果：** 赋予该容器 sticky 或 fixed 属性，并添加毛玻璃效果，使其浮动在文本上方，既方便操作又不完全遮挡视线。  
* **推荐 Tailwind 结构：**  
  JavaScript  
  \<div className="fixed bottom-0 w-full max-w-\[页面核心宽度\] pb-safe pt-4 px-6 bg-paper/80 backdrop-blur-md border-t border-ink-200/50 flex justify-between items-center z-50"\>  
     {/\* 左侧：精简的播放器控件（仅保留图标） \*/}  
     \<div className="flex gap-4 text-primary"\> ... \</div\>  
     {/\* 右侧：自评按钮组 \*/}  
     \<div className="flex gap-3"\>  
       \<button className\="px-6 py-2 rounded-full border border-primary text-primary hover:bg-primary/5 transition-colors"\>还不熟\</button\>  
       \<button className\="px-6 py-2 rounded-full bg-primary text-white hover:bg-primary/90 transition-colors"\>会背了\</button\>  
     \</div\>  
  \</div\>
