主旨：重构《唐诗画境》首页（Home Page）的布局与交互组件，提升整体的古典美感、视觉对称性与用户留卷率。

技术栈上下文：
- 框架：Next.js 16 + React 19 + TypeScript
- 样式：Tailwind CSS 4（请使用 v4 推荐的语义化 Token 或标准的 CSS 变量类）

重构目标与详细设计要求：

1. “今日一诗”核心区域重构（对齐详情页规范）
- 诗词正文排版优化：彻底移除当前包裹每句诗词的独立灰色圆角气泡框（Chat UI 样式）。将其合并为一个统一的、无边框、无独立背景的纯净文本容器。
- 字体与留白规范：诗词正文必须应用经典衬线体（font-serif），并设置充裕的行高（建议 leading-loose 或 leading-[2.0]）以及宽字距（tracking-widest），营造水墨留白的意境美。
- 引入连续打卡条（方案 B）：在“今日一诗”卡片的内部右上角（或“今日已读”按钮水平右侧）新增一个“7天连续打卡进度条（7-Day Streak Matrix）”。
  - 样式：包含一行轻量提示文本“本周打卡”，后跟 7 个精致的小圆点/小方块。
  - 状态：已打卡的日子（1-3天）使用品牌主色（bg-primary text-white）并显示对勾（✓）或高亮；未打卡的日子（4-7天）使用浅灰色低调呈现（bg-ink-100 text-ink-400），视觉上保持克制，不可喧宾夺主。

2. 底部功能入口矩阵重构（解法二：2x2 核心网格）
- “我的小档案”移出：从底部的网格中完全移除“我的小档案”卡片。将其重构为页面顶部 Header 区域（大标题右侧）的一个轻量化个人头像或图标下拉菜单。
- 剔除重复项：完全移除底部原有的“今日一诗”卡片，避免与首屏核心区域功能重叠。
- 新增入口：新增一个“顺序全集”功能卡片（文案可为“顺序全集 / 按编号浏览”，满足用户按 001-366 顺序系统学习的需求）。
- 完美 2x2 网格：将剩下的 4 个核心功能卡片（诗歌分类、顺序全集、挑战闯关、复习成长）重新编排为一个完美的 2x2 对称网格布局（在桌面端使用 grid grid-cols-2 gap-4 或 gap-6），彻底解决原先 4+1 头重脚轻的失衡感。

3. 设计规范与细节强化（Design Tokens）
- 请确保组件代码中使用的颜色与字体遵循以下语义（或转化为对应的 Tailwind 4 基础类）：
  - 页面背景：bg-paper (`#F7F5F0`)
  - 卡片/容器背景：bg-surface (`#FFFFFF` 或 `#FCFAF5`)
  - 主要文本（深墨）：text-ink-900 (`#2C2C2C`)
  - 品牌主色（黛蓝/暗调）：bg-primary / text-primary (`#354E6B`)
- 确保所有卡片的 Hover 态具备平滑的过渡动画（transition-all duration-300），鼠标悬停时伴随轻微上浮（hover:-translate-y-0.5）或柔和阴影加深。
